# Blog — widget TraTraBuilder

Cargo ya no contiene las noticias ni su layout. Pega una sola vez este
placeholder en la página Blog; los textos, links, orden, columnas y destacados
se editan en TraTraTrax Studio → Blog.

```html
<div data-ttx="blog"></div>
```

El script global `ttx.js` debe estar activo, como en los demás widgets.
